| Concept      | Purpose                                                                                                                      | Main Use                                                                                                               | Real-time Scenario                                                                                                                                          | Key Methods                                                                                      |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **VWRoster** | Represents a **list of items assigned to a workflow step or activity**. Think of it as a **dynamic view of workflow items**. | Fetch or filter items waiting for a **specific activity**, query based on conditions (like index values, ranges, etc.) | **Loan Approval Workflow**: Fetch all loan applications assigned to “Document Verification” activity with loan amount > ₹5 lakhs.                           | `createQuery()`, `next()`, `fetchCount()`                                                        |
| **VWQueue**  | Represents a **queue in the PE** where items **wait for a user or system** to pick them up. It’s like a **tray of tasks**.   | Fetch queue items, count pending items, display work items to users or roles.                                          | **HR Onboarding**: HR staff fetch all documents waiting in the queue “DocumentVerificationQueue”. Manager approves pending leave requests from their queue. | `getQueueName()`, `fetchCount()`, `createQuery()`, `getQueueElements()`, `getFieldDefinitions()` |
| **VWLog**    | Represents the **log of all workflow events**. Tracks what happened, when, and by whom.                                      | Audit, debug, trace workflow actions, error analysis.                                                                  | **Credit Card Application**: Track all events – submission, fraud check, approval, rejection. Check who approved a loan and when.                           | `createQuery()`, `next()`, `getLogEntry()`, `getFieldDefinitions()`                              |
