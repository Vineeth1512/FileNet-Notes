🟦 ⭐ ICN vs ACCE — COMPLETE EXPLANATION


---

1️⃣ TECHNICAL DEFINITION

ICN (IBM Content Navigator)

A web-based end-user interface to upload, search, view, manage documents and complete workflow tasks.

ACCE (Administration Console for Content Engine)

A web-based administration tool used by FileNet administrators to configure and manage Content Engine objects.


---

2️⃣ REAL-LIFE DEFINITION

ICN is like the customer counter/front desk of a bank.

Customers (end users) come here to:

Submit forms

View information

Make requests


ACCE is like the bank manager’s office.

Only authorized staff can:

Set rules

Configure systems

Control security


ICN = User Portal
ACCE = Admin Console


---

3️⃣ WHAT EACH ONE IS (Simple Explanation)

🟦 ICN (IBM Content Navigator)

Used by normal business users for daily work:

Upload documents

Search and view documents

Add metadata

Complete workflow tasks

Add annotations

Versioning

Download/Preview


🟥 ACCE (Admin Console for CE)

Used by administrators/developers to configure the system:

Create document classes

Create property templates

Manage object stores

Set security (ACLs)

Configure marking sets

Manage storage areas

Create folders at system level



---

4️⃣ WHY EACH TOOL IS USED (Purpose)

⭐ ICN Purpose

✔ End-user interactions
✔ Document handling
✔ Workflow inbox
✔ Searching
✔ Simple UI for business teams

⭐ ACCE Purpose

✔ Configure CE structure
✔ Build metadata model (classes, properties)
✔ Apply system-level security
✔ Manage Object Store
✔ Create events, subscriptions
✔ Troubleshooting & admin tasks
