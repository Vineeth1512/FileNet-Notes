🟦 ⭐ TEAMSPACES — COMPLETE EXPLANATION (ICN)


---

1️⃣ TECHNICAL DEFINITION

A Teamspace in ICN is a collaborative workspace where a group of users can store, organize, share, and manage documents together with a common folder structure, tasks, and permissions.

It is like a mini repository inside ICN designed for teamwork.


---

2️⃣ REAL-LIFE DEFINITION

Teamspace is like a shared project room where a team keeps all files, notes, tasks, and folders related to one project — only the team members can enter and work inside.

Example:

A room for HR hiring team

A room for audit team

A room for legal case team


Everyone in that team gets access to everything inside that room.


---

3️⃣ WHAT TEAMSPACES ARE (Simple Explanation)

A Teamspace provides:

✔ Shared folder structure
✔ Shared documents
✔ Shared searches
✔ Shared tools
✔ Team access control
✔ Templates
✔ Collaboration support

It acts as a virtual shared workspace inside ICN.

Teamspaces are great when multiple users must work together on the same content.


---

4️⃣ WHY WE USE TEAMSPACES (Purpose)

✔ To allow teams to collaborate on documents

For example, HR team working on employee onboarding.

✔ To isolate project content

Only project members see the teamspace.

✔ To organize content by project/department

Each teamspace has its own folders.

✔ To simplify sharing

Users do NOT need to set permissions on each document —
Teamspace manages it automatically.

✔ To support temporary projects

After the project ends, teamspace can be:

Archived

Exported

Deleted


✔ To reduce dependence on IT

Teams can manage their own space without admin help.


---

5️⃣ TEAMSPACE ROLES

Teamspaces support role-based access:

🧑‍💼 1. Teamspace Owner

Creates the teamspace

Manages members

Sets permissions

Controls folder structure


👥 2. Teamspace Member

Upload documents

Edit documents

View team content


👀 3. Read-only Member

Can view documents

Cannot upload/edit/delete

📌 Real-Life Analogy: A Project War Room / Shared Team Room

Imagine a company creates a room for a project team:

Inside the room:

Files are pinned on boards

Folders kept on shelves

---

8️⃣ TEAMSPACE VS FOLDERS

Concept	Teamspace	Regular Folder

Purpose	Collaboration area	General storage
Permissions	One time for whole team	Set manually on each folder
Members	Team-based	ACL-based
Tools	Searches, structure, tasks	Only storing files
Lifecycle	Can archive/delete	Permanent



---

9️⃣ TEAMSPACE TEMPLATES

Useful when:

Many teams follow same structure
