# 🚀 IBM Content Navigator (ICN) Plugin Setup in Eclipse

> A clean, step-by-step guide to **develop, build, and deploy an IBM Content Navigator plugin** using Eclipse.

---

## 🧩 Overview

This document explains how to:

* Configure Eclipse for ICN plugin development
* Create and build an ICN plugin
* Deploy and register the plugin in IBM Content Navigator

If you're working as a **FileNet / ICN developer**, this setup is essential.

---

## 🛠️ Prerequisites

Before starting, ensure you have:

* ✅ Eclipse IDE (compatible with your ICN version)
* ✅ IBM Content Navigator server access
* ✅ ICN Admin privileges
* ✅ Required ICN plugin JARs
* ✅ Access to the application server (VM / Remote Desktop)

---

## ⚙️ Step 1: Configure Eclipse for ICN

### ➕ Add ICN JARs to Eclipse

Copy the following JARs into the Eclipse **`dropins`** folder:

* `com.ibm.ecm.icn.plugin_2.0.3`
* `com.ibm.ecm.icn.plugin.202`
* `com.ibm.ecm.icn.facet.EDSPlugin.202`

> 🔧 **Troubleshooting Tip**
> If Eclipse does not recognize ICN features, place these JARs in the **`plugins`** folder instead.

🔁 **Restart Eclipse**

After restart, you should see **IBM Content Navigator** options while creating a new project.

---

## 🧪 Step 2: Create ICN Plugin Project

1. Open **Eclipse**
2. Select **New → Project → IBM Content Navigator Plugin Project**
3. Complete the wizard and finish
4. Create a **`lib`** folder inside the project
5. Add all required dependency JARs to the `lib` folder

---

## 🧱 Step 3: Configure `build.xml`

Open the `build.xml` file and add the following entries inside the classpath:

```xml
<pathelement location="./lib/Jace.jar" />
<pathelement location="./lib/navigatorAPI.jar" />
<pathelement location="./lib/stax-api.jar" />
<pathelement location="./lib/xlxpScanner.jar" />
<pathelement location="./lib/xlxpScannerUtils.jar" />
```

📌 These libraries are required to compile and package the ICN plugin correctly.

---

## 🏗️ Step 4: Build Plugin JAR

1. Right-click on **`build.xml`**
2. Select **Run As → Ant Build**
3. Verify the build completes successfully
4. Locate the generated **plugin JAR file**

✔️ Your ICN plugin JAR is now ready for deployment.

---

## 🚚 Step 5: Deploy Plugin JAR to Server

1. Login to the **Application Server / Remote Desktop**
2. Create a dedicated folder for ICN plugins (if not already present)
3. Copy the generated **plugin JAR** into this folder
4. Copy the **absolute path** of the JAR file

📍 Example:

```
/opt/ibm/icn/plugins/custom-plugin.jar
```

---

## 🧑‍💼 Step 6: Register Plugin in ICN

1. Open **IBM Content Navigator** in a browser
2. Login using **Admin credentials**
3. Navigate to **Administration → Plugins**
4. Click **New Plugin**
5. Paste the **plugin JAR file path**
6. Save and close

✔️ Plugin is now registered in ICN.

---

## 🖥️ Step 7: Enable Plugin on Desktop

1. Go to **Administration → Desktops**
2. Open the required desktop configuration
3. Add the newly registered plugin
4. Save the desktop

🔄 Refresh the ICN UI to see the plugin in action.

---

## 🎯 Final Result

✅ Eclipse configured for ICN development
✅ Plugin project created successfully
✅ Plugin JAR built using Ant
✅ Plugin deployed and registered in ICN
✅ Plugin enabled on ICN desktop

---

## 💡 Pro Tips (Interview Ready)

* Always match **ICN version ↔ Eclipse plugins**
* Restart ICN application if plugin does not load
* Check server logs for plugin initialization errors
* Keep plugin JARs in a centralized folder

---

🎉 **You are now ready to develop and deploy IBM Content Navigator plugins like a pro.**
