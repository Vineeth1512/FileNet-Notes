# 📌 Creating a Repository in IBM Content Navigator (ICN)

Follow the below steps to configure and create a FileNet repository in IBM Content Navigator.

---

## ✅ Step-by-Step Process

### **Step 1 – Open ICN Admin Desktop**
1. Login to IBM Content Navigator using administrator credentials.
2. Open **Admin Desktop** from the ICN home page.
3. From the left navigation panel, click on **Repositories**.
4. Click on **New Repository**.

---

### **Step 2 – Select Repository Type**
- Choose **FileNet Content Manager** as the repository type.
- Click **Next** to proceed.

---

### **Step 3 – Enter Required Repository Details**

In the repository configuration screen, provide the following information:

| Field | Description |
|------|------------|
| **Display Name** | User-friendly name of the repository |
| **ID** | Unique identifier for the repository (no spaces) |
| **Protocol** | Communication protocol (EJB or WSI) |
| **Server URL** | Content Engine connection URL |
| **Object Store Symbolic Name** | Internal name of the Object Store |
| **Object Store Display Name** | Display name shown in ICN |

---

### **Example Values**
- Display Name: VKM_FNOS
- ID: VKMFNOS
- Protocol: EJB
- Server URL: iiop://localhost:2809/FileNet/Engine
- Object Store Symbolic Name: FNOS
- Object Store Display Name: FNOS

---

---

### **Step 4 – Connect to Content Engine**

1. After entering all required details, click on the **Connect** button.
2. Provide FileNet credentials when prompted.
3. If the connection is successful, the repository will be created.

---

## 🎯 Final Step – Attach Repository to Desktop

After successful creation:

1. Go to **Desktops** in Admin Desktop.
2. Open your Desktop configuration.
3. Navigate to the **Repositories** tab.
4. Add the newly created repository.
5. Click **Save**.

---

### 🎉 Result

Your FileNet repository is now successfully configured and available for use in IBM Content Navigator!

---

## Notes

- Ensure the Content Engine server is up and running.
- Verify the Object Store name from ACCE before configuration.
- Prefer **WSI protocol** for easier configuration in modern environments.

---

### Need Help?

If you face any issues while connecting, check:

- Server URL correctness  
- Network connectivity  
- Credentials and permissions  
- CE client configuration (for EJB)

Happy Configuring! 🚀
